### پیش‌نیازهای آموزش

برای درک بهتر مطالب این مخزن، آشنایی با سه حوزه زیر ضروری است.

**۱. معماری کامپیوتر**

نام انگلیسی: ‎Computer Architecture‎

- ساختار CPU و حافظه
- واحدهای ورودی/خروجی (I/O)
- مفهوم Bus و اتصالات سیستمی
- سلسله‌مراتب حافظه و Cache

**۲. زبان برنامه‌نویسی C**

نام انگلیسی: ‎C Programming Language‎

- متغیرها و انواع داده
- عملگرها و دستورات شرطی
- حلقه‌ها و توابع
- اشاره‌گرها و مدیریت حافظه
- ساختارها و اتحادیه‌ها

**۳. ساختمان داده**

نام انگلیسی: ‎Data Structures‎

- لیست پیوندی
- پشته و صف
- درخت و درخت جستجوی دودویی
- جدول هش
- گراف
